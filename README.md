# Homebrew Tap

Homebrew formulae for [synapt](https://synapt.dev) tools.

## Installation

```bash
brew tap synapt-dev/tap
```

## Available Formulae

### gitgrip

Multi-repo workflow tool for synchronized branches, linked PRs, and atomic merges.

```bash
brew install synapt-dev/tap/gitgrip
```

Or after tapping:

```bash
brew install gitgrip
```

### Usage

```bash
gr status    # Check state across repos
gr sync      # Pull all repos
gr branch    # Create synchronized branches
gr pr create # Create linked PRs
```

See [grip](https://synapt.dev/grip) for full documentation.
